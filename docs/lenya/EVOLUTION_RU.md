# WifCam Helper / Лёня · эволюция без мусорных веток

1. Отдельная SD-прошивка Thingino/Raptor на Ingenic T23N, физические видеоканалы, звук и PTZ.
2. Минимальная рабочая microSD: MBR + FAT16 + Linux ext, компактная 81-МиБ IMG.
3. WifCam Helper :8090, долговременные настройки на SD, CGI Ollama и автозагрузка компонентов.
4. Acer Station v2.1: один процесс с прокси Ollama, Whisper, Piper и панелью управления.
5. Lenya v2.2: улучшенное пробуждение, физически подтверждённые микрофон, динамик и голосовой ответ.
6. Следующее поколение (план): Docker Brain Server на Huananzhi, RAG, граф, сценарии, память, Face ID, Speaker ID, PTZ-трекинг и мониторинг трёх узлов.

Основная ветка — main. GitHub предназначен для воспроизводимого проекта, а не для хранения личных IMG, тестовых паролей, незавершённых архивов и множества временных веток.

## Очистка устаревших веток

Обнаружены 7 дополнительных веток, все имеют коммиты, отсутствующие в main. Краткая история разработки выше не заменяет полного переноса исходного кода: ветка feature/acer-cpu-vision-ollama-20261104, например, содержит отдельный экспериментальный vision.py.

Подключённый GitHub-коннектор не предоставляет операцию удаления ветки. Поэтому ветки **пока существуют**. В локальном клоне можно использовать:

    .\scripts\prune-feature-branches.ps1
    .\scripts\prune-feature-branches.ps1 -Apply

Первый вызов ничего не удаляет. Второй показывает уникальные коммиты и требует точного подтверждения, прежде чем удалить **только семь перечисленных веток**. Ветка main не затрагивается. При необходимости перенесите ценный уникальный код в main до очистки.
