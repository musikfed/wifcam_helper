**Русский · 2026-11-11 · Lenya v2.2**

## Подтверждено
Рабочая физическая камера Ingenic T23N / SD, Raptor (видео, микрофон AAC, динамик PCM), HTTP-управление :8090; Acer Lenya Station v2.2 (Ollama-прокси :11435, Whisper/Piper :11436, панель :11437). В журнале подтверждён диалог HTTP 200 с генерацией PCM. Эталон — приватный `T23N_Lenya_WORKING.img`, размер **84 934 656 байт (81 МиБ)**. Два пути восстановления: полный IMG на SD и установка проверенного overlay по SSH; подробности в [INSTALL_RU.md](INSTALL_RU.md). Сам IMG, пароли и SSH-ключи не выкладываем на публичный GitHub.

## КРИТИЧНО: загрузка SD на Ingenic T23N
Заводская SPI NOR физически удалена: проверенная камера стартует **с microSD**. В известном образе **MBR**, раздел **FAT16 (0x0e) с LBA 2048, 16 МиБ**, раздел **Linux/ext (0x83) с LBA 34816, 64 МиБ**. Это **смещения разделов, а НЕ подтверждённые адреса MSPL/SPL/U-Boot/uImage**. Начальная область до LBA 2048, таблица MBR и загрузочные компоненты должны сохраняться **побайтово из эталона**: никакой авторазметки/переноса загрузчика/смещения SD для T23 без изучения реальных загрузочных заголовков и физического теста. `scripts/lenya-image.py` проверяет структуру разделов и компактизирует дамп, но НЕ удостоверяет корректность MSPL, железа и загрузки. Новый образ сначала сверить с эталоном, затем проверить на реальной камере с резервной SD. Не трогать рабочий Raptor, Wi-Fi, SSH, HTTP :8090.
