# Лёня · үлэлиир версияны бэлиэтээһин

**Саха тыла · 2026-11-11 · Lenya v2.2**

## Бэрэбиэркэлэммит
Ingenic T23N камера microSD-ттан үлэлиир, Raptor, веб-интерфейс :8090, Acer Lenya Station v2.2 (Ollama :11435, Whisper/Piper :11436, панель :11437). HTTP 200 уонна PCM куолас эппиэтэ бэрэбиэркэлэммит. 81 МиБ эталон IMG — туспа көмүскэллэр файл. [INSTALL_SAH.md](INSTALL_SAH.md).

## T23N загрузка смещениетэ
SPI NOR суох, загрузка microSD-ттан. Биллэр **раздел** LBA: MBR, FAT16 LBA 2048 (16 МиБ), Linux/ext LBA 34816 (64 МиБ). MSPL/SPL/U-Boot уонна ядро смещениелэрэ **бигэргэммэтэх**. Эталон IMG загрузка байттарын уонна MBR-ы уларытбакка хаалларар наада. Структура бэрэбиэркэтэ камера чын загрузкатын бигэргэтпэт.

## Үлэтэ ситэ илик
CORE Brain Server, RAG, билии графа, сценарий, планировщик, сирэй/куолас билиитэ, PTZ, рыжий куоска анимацията, үс компьютер мониторинга, Git-ка код толору көһөрүү. 7 артық ветка баар, иккитэ аһаҕас PR-га сыһыаннаах.

## Салгыы үлэ
Эталон IMG-ны көмүскээ, загрузка смещениетин бэрэбиэркэлээ, секрет суох кодтары main-ҕа киллэр, Huananzhi-га мозг сервера оҥор, Acer-га холбон. Таһынан таныһыы: сирэй снимога уонна куолас записи качествота сөп буоллаҕына эрэ сүһүөх салҕанар.
