# Лёня · два пути развёртывания

**Физически проверено на 11.11.2026:** T23N SD/Raptor, страница камеры :8090, запись AAC, воспроизведение PCM, Acer Station v2.2 (Ollama-прокси :11435, Whisper+Piper :11436, локальная панель :11437) и ответы HTTP 200. **Не готово:** Brain Server на CORE, RAG, граф, распознавание владельца по лицу/голосу, автоматическое PTZ-сопровождение.

## A. Из минимального IMG

Сохраняем T23N_Lenya_WORKING.zip или IMG **только локально**. Внутри могут быть Wi-Fi-параметры и SSH-ключи. Проверка без изменения:

    py -3 scripts\lenya-image.py "F:\peginelab\T23N_Lenya_WORKING.zip"

Проверенный архив содержит IMG размером 84 934 656 байт: MBR, FAT16 начиная с сектора 2048 (16 МиБ), Linux ext с сектора 34816 (64 МиБ). Образ уже минимальный. Для записи IMG на microSD используйте USBImager или Raspberry Pi Imager и тщательно выбирайте устройство: запись уничтожит прежнее содержимое выбранного диска. **Копировать IMG как обычный файл на карту бессмысленно.** Скрипт образа никогда не открывает физические устройства.

Для новой полной копии карты, снятой сторонним инструментом, создаём компактный файл с сохранением MBR и всех разделов:

    py -3 scripts\lenya-image.py "F:\backups\full-card.img" --compact-to "F:\backups\T23N_Lenya_NEXT.img"

Скрипт не меняет загрузчик, файловые системы или таблицу разделов и не гарантирует загрузку без проверки на настоящей камере.

После восстановления образа и физической проверки камеры: разворачиваем Acer Station из распакованного локального peginelab.zip (см. ниже). Если нужно обновить камерный агент — используем путь B поверх рабочей SD.

## B. На работающую SD через SSH, без создания IMG

На Acer сначала распаковать peginelab.zip, например в F:\peginelab. Здесь лежат исходники Lenya_Station_v2 и патч Lenya_Wake_Fix_v22; эти скрипты берут код **из локального проверенного архива**, а не из произвольной сетевой ветки.

    .\scripts\lenya-deploy-camera.ps1 -PackageRoot F:\peginelab
    .\scripts\lenya-deploy-camera.ps1 -PackageRoot F:\peginelab -Apply

Первая команда только проверяет камеру; вторая сохраняет предыдущие исходники на microSD, передаёт overlay через SSH и scp -O и вызывает штатный безопасный INSTALL_CAMERA.sh. Она не трогает Raptor, HTTPD, Wi-Fi и маршрутизацию, не перепрошивает и не активирует голос самостоятельно.

Далее Acer: остановить свою Run-Station.ps1 клавишами Ctrl+C и выполнить:

    .\scripts\lenya-install-acer.ps1 -PackageRoot F:\peginelab
    .\scripts\lenya-install-acer.ps1 -PackageRoot F:\peginelab -Apply

После этого в каталоге Acer Station: Setup-Station.ps1, при необходимости Setup-Voice.ps1, затем Run-Station.ps1. Не запускать параллельно старый Bridge v1: он занимает порт 11435.

Проверка только чтением:

    .\scripts\lenya-check-nodes.ps1

**Секреты, личные записи, исходные образы SD, station-config.json, client.conf не публикуются.** Сценарии установки не заменяют проверку физического железа. Направление эволюции: [EVOLUTION_RU.md](EVOLUTION_RU.md).
